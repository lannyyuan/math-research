# 补充插图清单（plate/*）

《小石猴点灯》绘本网页里，第七分及之后的各章、四个增补用“补充插图”配图。共 **28** 个 key，文件放在 `out/book_img/plate/<名字>.png`（16:9，建议 1920×1080；没有图时 `npm run book` 会自动生成“待配图：key”的水墨渐变占位图，不影响阅读和 QA）。

同一个 key 在不同页取不同的局部（`webapp/heroes.json` 里的 `fx / fy / z`：取景中心 0~1、放大倍数），所以**构图要把“取景”一栏写的东西放在对应的位置**——下面每个 key 都列了用到的取景和它在画面里的位置。第一~第六分用影片帧 `cue/01`~`cue/40`（见 heroes.json 顶部说明），不在这里。

## 统一画风与设定

- 水墨水彩：宣纸纹理、淡墨渲染、留白；线条收得住，不要卡通高饱和。和影片、封面（`ref/cover.png`）同一套。
- 色调克制：夜色靛蓝/灰蓝为底（#121A2E / #1E2A44 / #5A6B86），纸白 #EFE8D8，墨 #2A2622；**暖色只给“灯”**（宝珠、火种、火盆、灯笼、油灯：灰金 #cfc29a / #F3D98A）、奶奶的红头绳、小姑娘的红裙（朱砂 #B8382E），其余降饱和。
- 角色沿用 `ref/character-sheet.png`：石娃（9 岁男孩，补丁蓝灰短衣、旧布袋；后文长成少年、成年、老年）、龟甲（三寸长的灰白石猴，眼亮得像两点火星，约为石娃身高的 1/8）、奶奶（白发、红头绳、手巧）、小豆、国王、壮族（擂台上的壮汉）、画师、小孙女（红小褂）等。人物脸部不用画太细，剪影/半侧即可。
- 时间线：**第七分（主城见闻）发生在点灯之前**（天还黑，靠灯笼/灯火照明，天色深蓝泛灰蓝）；**第八分起在灯亮之后**（白天明亮柔和，晨光有一道金边）。少数 key 灯前灯后都用到，下面的“光线”里已写折中画法。
- 画面里不要放字（网页上图下面有小字图注）；需要出现的字（“老伙计”小石牌、册子第一页）可以写，但要小。

## 改图/换取景

- 画好后直接放进 `out/book_img/plate/`，重新 `npm run book` 即可；不用改 heroes.json。
- 觉得某个取景不对，改 `webapp/heroes.json` 里那一项的 `fx / fy / z`；要换成别的 key 就改 `img`。
- 如果画面里某块东西的位置和上面写的不一样，也只要改对应的 `fx / fy / z`。
