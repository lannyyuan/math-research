# PRD · 绘本网页「点字看拼音、听发音」（Hanzi Hover / Click Pinyin）

> 状态：**已确认并实现**（2026-10-11，见 §12）　版本：v1.0
> 适用：`stone-monkey-film/dist/xiaoshihou-book.html`（单文件、离线可读的绘本网页）
> 调研对象：`D:\Users\lanny\playground\KunKun-study\Pinyin_Drill_P0`（拼音练 v1.0.4，下称 **Drill**）

---

## 1. 一句话

读绘本时，把鼠标移到正文**任意一个汉字**上，字上方弹出它的**拼音（带声调）**；**点一下**就用**真人录音**念出这个字。触屏设备点一下 = 显示拼音并发声。

## 2. 调研结论：技术上够不够？

**结论：够，但 Drill 只能提供一半。**

Drill 不是“汉字→拼音”的转换引擎，而是一个**音节级的练习应用**：它的资产是**“拼音音节 → 真人 MP3”**，题库里没有汉字表（`catalog.json` 里只有 85 个汉字，全是说明文字）。所以本功能要分两层：

| 层 | 要做什么 | 来源 | 状态 |
|---|---|---|---|
| **A. 字 → 拼音**（含多音字、轻声、一/不变调） | 给书里每个汉字标上下文里的正确读音 | **Drill 没有**；需新增，用 `pypinyin` 在**构建期**离线标注 | 需新做 |
| **B. 拼音 → 声音** | 1–4 声音节的真人录音 | **Drill 有**：1,069 条真人 MP3（Chen Wang 王琛录音，CC-BY-SA-3.0）+ `catalog.json` 的音频清单与 SHA-256 | 可直接复用 |

### 2.1 Drill 里能复用的

| 资产 | 位置 | 说明 |
|---|---|---|
| 音节真人录音 | `human-audio-downloads/audio/cmn-{音节}{声调}.mp3` | 64 kbps、单声道、48 kHz，单条约 1.4 s、~12 KB；`ü` 写作 `v`（`lv4`） |
| 音频清单 | `catalog.json` → `audioSources` | 1,080 项：1,069 真人 + 11 TTS；含来源、许可、SHA-256 |
| 上游下载地址 | `AUDIO_SOURCES_AND_USAGE.md` | 固定 revision `ff9ed3d0…`，`…/64k/syllabs/cmn-{id}.mp3` |
| 署名文本 | `human-audio-downloads/AUDIO_CREDITS.md` | 可直接作为致谢文字 |
| 播放思路 | `audio.js`（`AudioBank`） | WebAudio 解码 + LRU（64 段）+ 取消/换音；**不直接搬**（见 §6.3） |

**不复用**：`engine.js`（三盒复习/间隔/统计）、`db.js`（IndexedDB）、`sw.js`（Service Worker）、`app.js`——和“点字发音”无关，且我们是 `file://` 单文件离线页，不能依赖 SW/IndexedDB。

### 2.2 用我们这本书的真实数据量出来的

对 `story/book_source.txt` 全文（17,286 个汉字 token、1,468 个不同汉字）用 `pypinyin` 标注后，对照 Drill 的音频库：

| 类别 | token 数 | 占比 | 处理 |
|---|---:|---:|---|
| 有真人录音 | 15,779 | **91.28 %** | 直接播放 |
| **轻声**（的/了/着/子/们/么/头/得…，共 24 个字） | 1,402 | **8.11 %** | Drill 只有 1–4 声，**没有轻声录音** → 需决策（§5.3） |
| 缺录音，但上游有（20 个音节） | 83 | 0.48 % | **补下载 20 个音节**（同一录音者、同一版本，已验证可下载） |
| 缺真人录音：`ju4`（Drill 只有一条 eSpeak 机械音，上游也是 404） | 22 | 0.13 % | 兜底（§5.4）；不采用 eSpeak 机械音 |

- 书里用到 **828 个不同的“音节+声调”**；Drill 有 807 个，缺 21 个；其中 **20 个可从上游补齐**（`bu2 gan4 niang2 ye2 zhao2 sou4 pian2 fa4 shao2 lao4 men1 ning4 bo4 nan4 lin1 shei2 bie4 sao4 zhou3 dei3`），只有 `ju4` 在上游也是 404。
- **所需音频总量**：807 条原始 MP3 ≈ **7.9 MB**（补齐后约 8.2 MB（每条平均约 9.8 KB））。
- **多音字**：书里有 56 个字出现不止一种读音，占 token 的 **16.7 %**（含一/不变调）。`pypinyin` 对多数字准确，但对**结构助词系统性出错**，抽样实证：
  - “写**得**一笔好字”“跳**得**高” → 标成 `de2`（应为轻声 `de`）；“总**得**有人做” → `dei3` ✓
  - “点**着**灯”“围**着**火堆” → 标成 `zhao2`；“戴**着**眼镜”“眯**着**眼” → 标成 `zhuo2`（应为轻声 `zhe`）；“睡**着**了” → `zhao2` ✓
  - “养鸭，**还**给猫备一只碗” → `huan2`（应为 `hai2`）
  → 必须加**规则 + 人工校对表**，不能裸用（§5.2）。

> 结论：**技术上充足**。风险集中在两处——多音字/助词的**读音正确性**（可用规则+校对解决）和 **8.1 % 轻声**（需选一种可接受的发音方案）。其余都是工程量。

## 3. 目标与非目标

**目标**
1. 正文任意汉字：悬停显示拼音，点击发声（真人录音优先）。
2. 保持“**单个 HTML、离线可读**”（`file://` 双击即用，不要 Service Worker / 服务器）。
3. 不破坏现有能力：全文逐字核对（`qa.mjs`）、翻页手势/快捷键、朗读本页、放映模式、字号/主题设置。
4. 读音**正确可审**：多音字和轻声有可复核的校对表，而不是黑盒。

**非目标（本期不做）**
- 不做拼音练习/测验/三盒复习（那是 Drill 的事）。
- 不做整句/整段拼音注音（ruby 全显）。可作为后续“全书注音”开关，本期不含。
- 不做录音评测/ASR、不做 TTS 合成新音色。
- 不改书里的任何正文文字。

## 4. 用户故事

| 角色 | 故事 |
|---|---|
| 孩子（6–8 岁，识字中） | 我看到不认识的字，把鼠标放上去就知道怎么读，点一下听老师读。 |
| 家长 | 我陪孩子读，想点某个字确认读音和声调；多音字（如“长”“得”）要读对。 |

## 5. 功能需求

### 5.1 交互（桌面鼠标）

```
正文：  …… 他  蹲  下  来 ，教  老  奶  奶 ……
                  ┌──────┐
        悬停 ──▶  │ xià  │  ← 气泡：拼音（带声调符号，大号）
                  │ 🔊   │  ← 小喇叭（提示“可点击”）；播放中喇叭动画
                  └──▾───┘
                    下      ← 当前字：淡色高亮底
```

| # | 需求 | 验收 |
|---|---|---|
| F1 | 鼠标悬停在汉字上 **≥150 ms** 显示气泡；移开 100 ms 后消失；气泡不遮挡所指的字，靠页边时自动翻到下方/侧边 | 真浏览器测试：hover 后 `.pyb` 出现且文字=期望拼音 |
| F2 | **点击**汉字（或点气泡的喇叭）播放该字发音；再次点击重播；播放时再点别的字，立即**打断**上一个 | 点击后 `audio` 触发 `playing`；连点无叠音 |
| F3 | 只对**汉字**生效；标点、空白、字母不响应，不出气泡 | 标点 hover 无气泡 |
| F4 | 多音字按**上下文**显示读音（“长大”zhǎng、“长街”cháng），并保持**文字内容不变**（`textContent` 逐字相同） | `qa.mjs` 全文核对仍为“✓ 逐字相同” |
| F5 | 轻声：气泡显示**无声调符号**的拼音（如 `de`），附一个小标记“轻声” | 见 §5.3 |
| F6 | 一/不变调按教材通行写法显示（`yí ge`、`bú shì`）；**三声连读不改写**（仍标原调） | 抽查 |
| F7 | 无录音可用时：仍显示拼音，喇叭变灰，点击不报错（§5.4 兜底链） | `ju4` 的字 |

### 5.2 触屏 / 手机 / 平板

- 无 hover：**轻点一个字 = 显示气泡 + 立即发声**；轻点空白处/再点别的字切换。
- **不得干扰**现有翻页手势（`stage` 上的 `pointerdown` 滑动判定）和点击翻页区：位移 >10 px 视为滑动，不算点字。
- 触屏/鼠标的判别沿用现有 `e.pointerType === 'mouse'`。

### 5.3 设置与默认值

在现有**设置面板**（`app.js` “设置”）新增一行：

| 项 | 取值 | 默认 |
|---|---|---|
| 点字看拼音、听发音 | 开 / 关 | **开** |
| 悬停即发声（不用点击） | 开 / 关 | **关**（避免鼠标划过时一路乱响） |

保存在现有 `localStorage` 的 `xiaoshihou.v1`；读不到存储时用默认值，不影响读书。

### 5.4 读音数据与发音兜底链

**每个字的数据**：`拼音（含声调数字，如 zhang3）`、`显示形式（zhǎng）`、`发音 id`（对应音频库）。

**发音兜底链（按顺序，命中即止）**
1. 该“音节+声调”的**真人录音**（Drill 库 + 补下载的 20 条）。
2. **轻声**：按 §5.3.1 的轻声方案。
3. 浏览器 `speechSynthesis`（`zh-CN`，朗读该单字）——应用已有“朗读本页”在用它；离线不保证，**可用才用**。
4. 都没有：只显示拼音，不发声（F7）。

#### 5.3.1 轻声方案（8.1 %，需验证后定稿）

轻声只有 24 个字，其中 **的(428) 了(377) 着(196) 子(157) 们(77) 么(47) 头(41)** 占绝大多数，是孩子最常点的虚词。候选方案：

| 方案 | 做法 | 优点 | 风险 |
|---|---|---|---|
| **N1（推荐先试）** | 取该字**本调**录音，**截短到约 0.3 s + 渐弱 + 降音量**模拟轻声 | 离线、统一、可审 | 需耳听验收；是“模拟”不是真轻声 |
| N2 | 轻声字固定映射到某一声录音（如 的→`de1`） | 实现最简单 | 声调明显不对，教学上有误导 |
| N3 | 轻声字用 `speechSynthesis` | 系统声音通常会念对轻声 | 不离线保证；各设备音色不一致 |

→ 实现前先做一个 **10 分钟试听 Spike**：对 的/了/着/子 各生成 N1/N2 两种样本，由家长试听选定（Drill 本身的原则也是“发音由家长/教师验收”）。

### 5.5 范围

- **做**：阅读页正文里的汉字、章名。
- **不做**：封面标语、目录/分镜缩略文字、放映模式的字幕条、设置面板里的 UI 文字、页脚。

## 6. 方案设计

### 6.1 总体架构（构建期完成“字→音”，运行期只“查表+播放”）

```
story/book_source.txt
        │  plan.py（已有：分页/分段）
        ▼
  每段 text ──▶ ① pinyin_annotate.py（新）
                    pypinyin(上下文) → 规则覆盖(得/着/地/还…) → 校对表 pinyin_overrides.json
                    └─ 输出：每段 py: ["yi1","shuo1",…]（与段内汉字一一对齐，数量不等直接构建失败）
        ▼
  build.py（已有）：
    ② 取出全书用到的“音节+声调”集合 → 从 Drill 复制真人 MP3（+补下载20个）→ 裁静音/转码 → base64 内联
    ③ 把 py 数组和 音频表 写进 HTML 数据区
        ▼
  app.js（已有）：渲染时把汉字拆成 <span class="hz" data-i="…">；悬停/点击 → 查表 → 气泡 + 播放
```

**为什么构建期标注、不在浏览器里转换**：（a）全书文本固定，没必要运行期带词典（`pinyin-pro` 等词库 1–3 MB，且多音字同样会错）；（b）构建期可以出**校对报告**、可单测；（c）运行期零依赖，符合“单文件离线”。

### 6.2 数据格式（写进现有 `book-data`）

```jsonc
// 每个 para 新增（与 text 里的汉字按出现顺序一一对应；标点/字母不占位）
{"text": "…教她把绳头绕两转…", "py": ["jiao4","ta1","ba3","sheng2","tou2","rao4","liang3","zhuan3"], "tag": …}
// 全局
"pinyinAudio": {"ma3": "data:audio/mpeg;base64,…", …}      // 约 830 条
"pinyinRules": {"neutral": {"的":"de2","了":"le4", …}}        // 轻声方案用到的本调表（§5.3.1 定稿后填）
```

- 显示形式由构建期或前端用“声调数字→符号”一个 20 行小函数得到（`a e o` 标调规则 + `ü`）。
- 字体：现有 `subset_font.py` 按“全部文字”裁字体，新增的拼音字符（`āáǎà…ǖǘǚǜ`）会**自动进入子集**（构建脚本取 `ord(ch)>127` 的全部字符）。

### 6.3 播放层

- 用 **`HTMLAudioElement`（data URI）**，不用 `fetch`+WebAudio：`file://` 下 Chrome 对 `fetch` 本地文件有 CORS 限制，而内联 data URI 一定可用。
- 每个音节一个 `Audio` 对象，**LRU 缓存**；翻页时在 `requestIdleCallback` 里预载**本页**用到的音节（平均 92 字、最多 172 字）。
- 全局单实例“当前发音”：新播放前 `pause()` 旧的；与“朗读本页”(`speechSynthesis`) 互斥——任一开始就停掉另一个。
- 目标延迟：已预载 ≤150 ms；未预载 ≤400 ms。

### 6.4 体积预算

| 方案 | 音频体积 | 内联后 HTML 增量 |
|---|---:|---:|
| 原始 MP3（807+20 条） | 8.2 MB | ≈ +11 MB（HTML ≈ 16 MB） |
| 转 32 kbps 单声道（实测 807 条） | 4.6 MB | ≈ +6.2 MB |
| AAC 24 kbps（实测） | 3.8 MB | ≈ +5.1 MB |
| 再**裁掉首尾静音**（单条 1.4 s，语音只占约一半，待实测） | 预计 ≈ 2–3 MB | ≈ +3–4 MB |

→ **推荐**：裁静音 + 32 kbps MP3（兼容性最好，Safari/Chrome/Edge 都认），HTML 控制在 **≤ 10 MB**。若听感不接受，退而用原始文件放 **sidecar 目录** `dist/pinyin-audio/`（`<audio src>` 在 `file://` 下可用），但就不再是“单文件”。

### 6.5 许可（必须做）

录音为 **CC-BY-SA-3.0**（Chen Wang 王琛 / Wang Chen、Lopez Hugo、Vion Nicolas，`hugolpz/audio-cmn`）：
1. 设置面板或页脚加**“致谢”**：录音者、来源链接、许可名称与链接；
2. 注明“**已裁剪静音/转码**”（CC 要求标明改动）；
3. 转码后的音频仍按 CC-BY-SA-3.0 分享；书本身的文字/插图不受该许可约束（分别标注）；
4. 保留 Drill 的提示：“**这些是发音候选，不是教材认证录音**”。

## 7. 非功能需求

| 项 | 要求 |
|---|---|
| 离线 | `file://` 双击可用；不联网、不加载外链；不依赖 SW/IndexedDB |
| 性能 | 一页 ≤172 字 → 最多 172 个 `<span>`；事件用**委托**（页容器一个监听），不给每个字绑监听 |
| 无障碍 | 汉字 `<span>` **不加 role/aria**，避免读屏器逐字播报；气泡 `aria-live="off"`；设置里可整体关闭；键盘逐字导航列为 **P1** |
| 隐私 | 不采集、不上报 |
| 兼容 | 桌面 Chrome/Edge/Safari/Firefox 最新版；iPad Safari（触屏路径）；`prefers-reduced-motion` 时关喇叭动画 |
| 回归 | 不改变版面分页（行高/字距不变）；`qa.mjs` 全文核对、桌面无滚动页、无控制台报错三项**保持通过** |

## 8. 验收标准

1. **文本不变**：`node webapp/qa.mjs` → “逐字相同（20573 字）✓”；桌面 1440×900 无需滚动的页仍为 0。
2. **覆盖率报告**（构建期输出）：汉字 token 100% 有拼音；有**真人音**的占比 ≥ **91.7 %**（补下载 20 个音节后：91.28 % + 0.48 %；轻声 8.11 % 另计）；缺音频字列表 = `ju4` 的 22 处 + 兜底说明。
3. **多音字校对**：56 个多音字的**全部出现处**（约 2,900 token）导出 `pinyin_review.csv`（字、读音、前后文）；**家长/你过一遍并签收**；结助词（得/着/地/还/的/了）规则单测通过（含上面 7 个反例）。
4. **交互**（真浏览器）：hover→气泡文字正确；click→`playing`；连点无叠音；标点无响应；触屏轻点可发声且不触发翻页。
5. **体积**：`xiaoshihou-book.html` ≤ **10 MB**。
6. **许可**：致谢可见，内容与 `AUDIO_CREDITS.md` 一致。
7. **试听验收**（人工）：抽 30 个高频字 + 全部轻声字试听，家长签收；不通过的字进 `pinyin_overrides.json`。

## 10. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 多音字/助词读音错 | 误导识字的孩子 | 规则 + 全量校对表 + 单测；“读音可审”是验收项 |
| 轻声无录音 | 8.1 % 的字发音不准 | M0 试听选方案；轻声字只有 24 个，可逐个人工定 |
| 录音是“发音候选” | 非教材认证 | 在致谢里如实标注；家长可关闭功能 |
| HTML 变大 | 加载慢 | 裁静音/转码；超预算则用 sidecar 目录 |

## 12. 决策记录与实现结果（2026-10-11）

**你的确认**：① 悬停只显示拼音、点击才发声（默认）；② 轻声方案“你直接定稿”；③ 体积方案同意；④ 范围同意。另：**不要一万个声音文件**——同音只存一条，不在仓库里存音频。

| 决策 | 结果 |
|---|---|
| 悬停 / 点击 | 悬停显示气泡，点击发声；设置里另有“悬停即发声”，默认关 |
| 轻声（定稿） | N1：取该音节现成录音里最接近低而短的一声（优先 3、4、2、1 声），构建期截短 0.30 s、渐弱、降音量 15%，生成独立的 `xx5` 片；**未经人耳验收**，致谢与 README 如实标注“模拟”；可在 `pinyin_overrides.json` 的 `neutral.individual` 逐字改 |
| 体积 | 裁静音 + 32 kbps 单声道；846 条共 3.21 MB；`dist/xiaoshihou-book.html` 9.70 MB（≤10 MB），仍是单文件 |
| 音频数量 | 全书 17,180 个汉字 → 847 种读音 → **846 条录音**（同音共用；ju4 无录音）；仓库只存 `pinyin_audio_manifest.json`（id、来源、SHA-256），录音源是 Pinyin_Drill 文件夹（只读）+ 上游补 18 条（缓存在 `out/`，不进 git） |
| 范围 | 正文 + 章名；封面标语、目录、放映字幕、设置面板文字不处理 |

**与 §6 草案的差异**
- 播放层改用 **WebAudio**（`OfflineAudioContext` 提前解码 + `AudioContext` 播放，LRU 200 条），而不是 `HTMLAudioElement`：解码不受“先点一下”限制，翻页后空闲时预解码本页音节，点击几乎即时；内联 data URI 在 `file://` 下可用。
- “谁”统一用 shuí（音频库里有），不用 shéi；`得/着/地/落/长/种/背/看/担/还…` 共 40 余条规则，见 `pinyin_overrides.json` / `pinyin_review.md`。
- 轻声的 24 个字实际生成了 21 条轻声片（其余音节本调与别处共用底片）。

**验收结果**：全书汉字 100% 有读音；99.87% 有真人发音（缺的只有 ju4×22）；`qa.mjs`（全文逐字相同 20573 字、桌面无滚动页、无控制台报错）与 `qa_pinyin.mjs`（数据 4 项 + 悬停 12 项 + 点击 4 项 + 开关 4 项 + 触屏 3 项 + 无报错）全绿；`test_pinyin.py` 8 项规则回归全绿。**待你做**：抽听轻声字和高频字（见 `pinyin_review.md` 复核多音字）。
