# 06 · 中文故事 + 水墨水彩风（《小石猴点灯》的做法）

参考实现：`stone-monkey-film/`（4 分 55 秒，8 个场景，中文字幕，绘本网页 20 多章）。
和 05（英文 + 设定图 + 白雪夜色，参考实现 `lighthouse-light-film/`）相比，这一版多出来的东西：

| 新问题 | 做法 | 代码 |
|---|---|---|
| 画风是**水墨水彩**（宣纸、飞白、皴擦、留白），不是儿童绘本的平涂 | 自己写一套“笔法工具”：变宽墨线 `brush`、短促笔触 `flicks`、透明水彩块 `wash`（边缘积色）、山 `mountain`（层层罩染 + 皴 + 山沟）、雾 `mist`、松/老树/柳/竹、石、茅屋；整张图再过一遍 `watercolorize`（颗粒、积色、湿边、轻微手抖）；最后整片叠一层宣纸纹理（soft-light） | `scripts/paint/pt.py` `cn.py` `make_paper.py` |
| 一幅画要有 **夜色 / 被光照到 / 白天 / 晨光** 几种样子 | 先用“中性淡彩”把明暗层次画好（颜色已降饱和），再用 `grade.py` 出各个版本：夜色 = 亮度 → 色带的渐变映射（深夜 #121A2E → 靛蓝 #1E2A44 → 灰蓝 #5A6B86 → 纸白 #EFE8D8，保证只落在色板里）；光照版 = 降饱和的自然色；晨光版 = 红霞/紫霞渐变叠在天空上。`save_plate()` 一次写出所有版本并登记 `public/bg/manifest.json` | `grade.py` `ccommon.py` `bg_village.py`（样板） |
| **光是叙事主线**：宝珠只照三尺，光照到哪里，那里才有颜色 | 整个世界画两遍：夜色版 + 光照版，光照版用若干个**跟着宝珠走的圆形软蒙版**叠在夜色版上，再叠一团灰金的柔光。蒙版的圆心要换成屏幕坐标：`project(cam, p, 世界坐标)`（和视差层同一个公式） | `src/fx/Light.tsx` 的 `Lit`；`src/fx/Stage.tsx` 的 `project` |
| 转场不许闪白/硬切，要“水墨晕染或纸面翻过” | 水墨晕染：一张灰度“显现图”（噪声 + 距离，值小的先显现）经 SVG `feComponentTransfer` 阈值化当蒙版，后一个镜头从某一点洇开盖在前一个上，边缘再叠一圈淡墨；`ShotStack` 管一个场景里的镜头序列（盖严之后前一个镜头不再渲染） | `src/fx/InkIn.tsx` `ShotStack.tsx` `scripts/make_ink_maps.py` |

| 设定表上的造型和任务书冲突（老龙眼神凶、龟甲画大了、金鼓高饱和） | 抠图**之前**直接在设定表上修（重画眼皮/眉毛/嘴角、胸前加裂纹）；大小比例统一在 `cast.tsx` 一处决定；金鼓降饱和 | `scripts/retouch.py` `make_sprites.py` |
| 字幕带不能压角色 | 镜头用 `atg(世界x, 缩放z)`：缩放时让角色脚底落在屏幕 y≈820（字幕带上沿 845）；`CharsCtx` 分三档（2 全画 / 1 不画角色 / 0 什么动的都不画），`audit_band.py` 对每条字幕的三个时刻做“全画 − 只有背景”的差，带区里有差异就报 | `src/scenes/kit.tsx` `src/fx/Variant.tsx` `scripts/audit_band.py` |

## 并行分工（人太多、图太多时）
一个人画完 20 块背景 + 30 个人物不现实，也画不一致。做法：
1. 先自己把工具箱（`cn.py`）和一块“样板板”（`bg_village.py`）画到满意，把影片的一个场景完整做出来（本例是 S1），确认整条链路（画板 → 夜色/光照 → 镜头 → 光池 → 水墨转场 → 字幕带）。
2. 写一份**画板清单** `scripts/paint/PLATES.md`：坐标系、地面线、字幕带禁区、图层/变体约定、色彩硬规则、每块板的尺寸和**关键物件的坐标**（门洞在哪、桥在哪、桌子在哪……），因为场景里的角色和动作是按这些坐标摆的。
3. 拆给几个子任务并行：水（江/海/海底）、山与室内、城/塔/天/火山、人物与道具、网页。每个人只改自己的文件，共享的 `sprites.json` / `manifest.json` 只增不覆盖。
4. 场景代码可以边画边写：先按清单里的坐标写，板子到了再对。

## 踩过的坑
- 山做成“每列按斜率上色”会出现竖条纹的“窗帘”——要用“每座峰的背光斜面罩染 + 山沟 + 皴擦”。
- 纯噪声（块状插值）做水墨转场的显现图，边缘会出现横平竖直的方块——要用高斯模糊的白噪声叠加，再做域扭曲。
- 把整张图的 `hash(name)` 当随机种子，每次运行结果不一样（Python 字符串哈希是随机的）——用 `zlib.crc32`。
- `pathLength` 要写在 `<path>` 上，写在 `<g>` 上无效（裂缝的描边动画一开始就露出来）。
- 把设定表上的手臂抠下来当可转动的块时，身体上手臂的位置不能用 `cv2.inpaint`（大块区域会糊成方块），用周围布料的平均色 + 噪点 + 几块污渍去补。
- 在两次 commit 之间反复重画的背景图（每块板几 MB × 变体）别提交进仓库，定稿前 `.gitignore` 掉，最后一次性提交。
