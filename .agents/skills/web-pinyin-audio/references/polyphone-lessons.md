# 多音字：怎么审、怎么写规则、哪些规则不能照抄

读音是这个功能里**唯一会“悄悄做错”的环节**：页面不会报错，孩子却会学到错的读音。所以多音字审校不是可选项。

## 1. 规则怎么写

规则文件是 JSON（见 `../assets/rules.starter.json`），`rules` 按顺序执行，后面的覆盖前面的：

```json
{"ctx": "(?:越|也|再)«种»", "py": "zhong4", "when": ["zhong3"], "note": "种（zhòng）：越种越多"}
```

- `ctx`：正则；用 `«字»` 标出要改的**那一个字**，前后是上下文（可以用正则：`(?<![已归])«还»给`、`(?:越|也)«种»`）。
- `py`：改成的读音。声调数字，轻声=5，ü 写作 v（`nv3`、`lve4`）。必须是录音库里有的音节。
- `when`：可选；只有当前读音（pypinyin 给的，或前面规则改成的）在这个列表里才改。**只想纠正 pypinyin 的默认值时一定要写**，这样不会把别的规则已经改对的又改回去。
- `ctx` 里的 `\1` 指 `ctx` 自己的第一个括号（程序用命名组标目标字，不占编号），可以放心写叠词规则，如 `([一-鿿])\1«地»`。
- 先在命令行试：`python -X utf8 scripts/pinyin_annotate.py --rules my_rules.json "要试的句子"`。

## 2. 审校流程（每个项目都要做一遍）

1. `python -X utf8 scripts/pinyin_annotate.py --review 文件1 文件2 --rules my_rules.json --out pinyin_review.md`
2. 打开 `pinyin_review.md`：第一部分是**全文里出现不止一种读音的字**（带上下文）；第二部分是**被你的规则改过的位置**。逐条看“上下文 → 读音”。
3. 优先看高频多音字：的 了 得 着 地 长 行 还 为 都 数 重 传 背 看 种 难 好 少 干 降 倒 调 间 空 没 相 发 假 将 教 量 乐 角 解 率。
4. 不对就加/改一条规则，**同时把典型例句加进单元测试**（参考 `../tests/test_skill.py` 的写法），重跑 review。
5. 把 `pinyin_review.md` 交给人（家长/老师）抽查；报告里写明“读音由 pypinyin + N 条规则生成，已审校高频多音字，不保证 100% 准确”。

## 3. 一篇文章调出来的规则，放到别处会改错（实测）

`example-rules-xiaoshihou.json` 是为《小石猴点灯》一本书调的 41 条规则，对那本书逐条审过。下面是把**同样的规则**用在别的句子上的实测结果（pypinyin 0.55）——这就是为什么起步规则里没有它们：

| 字 | 句子 | pypinyin 默认 | 那本书的规则后 | 正确 |
|---|---|---|---|---|
| 长 | 校长 / 班长 / 成长 / 生长 / 长辈 | zhǎng ✓ | cháng ✗ | zhǎng |
| 得 | 获得 / 取得 / 心得 / 难得 | dé ✓ | de（轻声）✗ | dé |
| 得 | 得到 / 得知 / 得意 / 得分 | dé ✓ | děi ✗ | dé |
| 着 | 着手准备 / 沉着冷静 | zhuó ✓ | zhe（轻声）✗ | zhuó |
| 着 | 用得着 | zhe ✗ | zháo ✓ | zháo |
| 地 | 高兴地说 / 开心地笑 / 认真地看 | dì ✗ | dì ✗ | de（轻声） |

要点：**每条规则都隐含“这个字在这篇文章里只有这几种用法”的假设**。换一篇文章，这个假设就不成立。所以只在**你审过的那份文本**上启用它们；新的文本重新审。

## 4. 起步规则之外，pypinyin 默认值已知会错的地方（实测）

| 句子 | pypinyin 给 | 正确 | 备注 |
|---|---|---|---|
| 字写得好看、跑得快、冷得发抖 | dé | de（轻声） | 结构助词“得”：要按你文本里“动词+得+补语”的写法加规则 |
| 我们得走了、你得小心 | dé | děi | 情态“得” |
| 点着灯、围着火堆 | zháo | zhe（轻声） | 助词“着” |
| 高兴地说、认真地看 | dì | de（轻声） | 助词“地”：叠词/AABB 起步规则已覆盖，其余按你的形容词表加 |
| 下一行 | xíng | háng | |
| 背起书包 | bèi | bēi | |

这些是**这次用样例页和书实测遇到的**，不是穷举。

## 5. 起步规则里有什么、为什么只有这些

`rules.starter.json` 只放“放到任何中文文本里都不会改错”的几条：叠词/AABB+地（慢慢地、安安静静地）、长长的、谁→shuí（录音库里只有 shui2）。其余一律先 review 再按文本加。

## 6. 轻声

轻声字（的、了、着、子、头、们、吧…）约占一本儿童书的 8%。录音库没有轻声录音，`pinyin_clips.py` 用该音节另一声的录音截短渐弱来**模拟**（`neutral.prefer` 决定用哪一声当底本，`neutral.individual` 可以逐个指定）。这是近似，不是真人轻声：页面致谢里已写“轻声为模拟”，**不要删这句**。想要真人轻声，把录好的 mp3 直接放进库目录（文件名 `de5.mp3`），并从 `manifest.json` 删掉那条记录，构建时会按手工放入登记。
