# 01 · 做 MP4：从故事到成片

对应参考实现 `snow-lamp-film/`。时间：4 核无显卡容器里，渲染约 35–40 分钟，其余是写代码和看图。

## 1. 拆情节、定时间线（`src/timeline.json` 是唯一数据源）

```jsonc
{ "title": "雪地里的那盏灯", "fps": 30,
  "scenes": [
    {"id": "s1-lost", "len": 30.5, "cues": [
       {"text": "发现自己一个人站在一片大森林里。", "gap": 2.0},   // gap = 上一条结束后静默几秒（默认 0.6）
       {"text": "远远的山顶上，有一点小小的光"}, … ]}, … ] }
```

- 场景 = 一个必须的情节点；参考实现 11 场（含片头），时长 5 / 30.5 / 21 / 22 / 35 / 30 / 31.5 / 17 / 36.5 / 34 / 28 = 290.5 s，40 条字幕。
- 每场只挑原文里**最关键的 3–5 句**当字幕，宁可少；字幕之间留白，画面和音乐自己讲故事（参考实现里约 69% 的时间有字幕）。
- 其余章节（支线、知识点、对话）不进影片，进绘本（见 02）。
- 场景和字幕的时间**由 `src/schedule.mjs` 算出来，渲染和检查共用同一份**，不要在场景代码里手写字幕时间。
- 场景代码里的动作按“场景内秒数”写；要对齐字幕就用 `schedule(scene)` 返回的 `t / d`。

## 2. 字幕规则与检查器（`scripts/check-subtitles.mjs`，必须全绿）

| 规则 | 实现 |
|---|---|
| 只用原文 | 每条（去掉引号/空白，去掉首尾 `，、；：`）必须是 `story/source.md` 的连续子串；两条带 `\n` 的是同一句分两行显示 |
| 停留时间 | `minDur = 1.6 + 0.30 × 汉字数`（标点 0.25 个字）；实际停留再 +0.2 |
| 版面 | 单行 ≤ 18 字符、≤ 2 行；单行字号 76 px，两行 64 px；底边距 74 / 50 px；半透明深靛蓝底；淡入淡出各 0.35 s |
| 间隙 | 条与条之间 ≥ 0.3 s；字幕不能越过场景结尾 |
| 总长 | 240–300 s |
| 副产物 | 写出 `story/subtitle-chars.txt`（字幕用到的所有字）→ 给 `subset_font.py` 裁字体 |

字幕太长不要改写：换成原文里更短的片段（不超过一句里的半句也行）。拟声字、生僻字想避开时同理。

## 3. 画法引擎（让程序画出“松快的墨线 + 透明水彩”）

文件：`src/art/ink.ts`、`ArtView.tsx`、`geom.ts`（模板在 `templates/engine/art/`）。

**墨线 `ink(points, opts)`**：把折线样条平滑后，沿线生成“变宽多边形”：
- 宽度 = 基础宽 × 收笔曲线（两端细）× 压力（噪声 + 下行略重）；
- 垂直方向叠一个缓慢的手抖噪声（`wobble`）；
- 按噪声随机“断笔”（`broken`）；
- `sketch()` 再画 1–2 遍更细更淡、偏离轮廓、两端出头的**起稿辅助线**；`guide()` 画辅助圆。

**水彩 `Art` 类**：`fill/shade/line/shape/wash/guide`，最后 `build()` 出 `{fills, ink, sketch}` 三层；`ArtView` 渲染：
1. 色块层：整体平移 `(dx, dy) ≈ (3.5, 3)` px，**溢出线外**；SVG 滤镜 `wc0–2`：`feTurbulence` 位移（边缘不规则）→ 颗粒 alpha → `feMorphology` 腐蚀后相减得到“边缘积色”（比中间深）；
2. 阴影层：滤镜 `ws0–2`，颗粒更重、透明度 0.3–0.4 的蓝灰 `#6b80b4`；
3. 起稿线（灰蓝，低透明度）；
4. 墨线（`inkRough` 小位移滤镜，边缘洇开）。

**注意**：`blob()` 用样条平滑，**只有 4 个角点的矩形会被抹成椭圆**。要直角（房子、城墙、窗）就先把每条边加密（`dense()`，见 `Plates.example.tsx`）。

**烘焙大背景**：天空、远/中林剪影、雪地、山、山洞、纸纹用 `Bake` 合成（`src/bake/`）渲成 PNG/JPG（`scripts/bake.mjs`），影片里只做平移/缩放；这样一帧里实时画的东西很少，渲染才跑得动。

## 4. 角色（纸偶）

- 一个角色一个组件，部件各自是一个 `Art`（身体、头、四肢、尾、围巾…），关节用 SVG `rotate(angle, 轴心)`；
- 动作由 props 驱动（`walk / lean / head / armN / armF / sit / hang / raise / eyes / flip`），内部只做呼吸、点头、摆耳、走路摆腿；转身是水平翻转（中间经过 0 的 `turnScale`）；
- 角色**原点在脚底中央、朝右**，`s` 缩放，`x, y` 摆位；背包/鹿背等“搭载物”用 `children`（局部坐标）；
- 配角用不同的参数/配色复用同一个组件（小石头 → 爸爸/妈妈：`variant`）；
- 原创设定写进 README（例：白鹿没有翅膀、不像马，鹿角是程序生成的“两棵小树”，春天长新叶）。

## 5. 场景与镜头

- `Stage` + `Layer p={0..1}`：p=0 在无穷远（不随镜头平移），p=1 是角色所在地面；镜头用关键帧 `{t, x, y, z}` + 正弦缓入缓出（`useCam`）；
- 固定版面：**地平线 `HZ=560`，角色脚底线 `GY=770`**，字幕带在 y>860 以下，角色不进字幕带；镜头对准世界坐标用 `at(wx, wy, z)`（别手算平移，符号很容易错）；
- 全片镜头都是缓慢的推、拉、摇；场景之间只有一小段明暗过渡（`SceneWrap`），没有快切；
- 雪：三层（远小慢、近大快），全片都在下，到“冰雪化开”那场逐渐停止；
- 灯是**视觉线索**：几乎每场都有（远处山顶 → 洞口 → 窗边 → 老油灯），唯一带光晕/星芒/闪烁的暖色；
- 紧张但不吓人（落水、狼）：慢推镜头 + 安静 + 低沉长音；水面柔和蓝色，角色一直露头；狼又小又冷，没有露牙和突然动作；
- 一个场景一个文件（`S0…S10.tsx`），在 `scenes/index.ts` 里按 id 登记，`Film.tsx` 按时间线排起来。

## 6. 字体与配乐

**字体**：霞鹜文楷（LXGW WenKai，SIL OFL 1.1，npm 包 `lxgw-wenkai-webfont`）。`scripts/subset_font.py` 按 `subtitle-chars.txt` 取出所需切片，用 fontTools 合并成一个 woff2（字幕用字 160 个 → 37 KB），附 `OFL.txt`。运行时用 `FontFace` + `delayRender` 加载（`fx/fonts.ts`）。

**配乐**（`scripts/make_music.py`，纯 numpy，不用采样）：
- 音色：钟琴/音乐盒（A5–D6–F#6 加 E6 为“灯”的主题）、拨弦、长音 pad、笛子；
- 质感：噪声（风/火/水/雨）、FFT 卷积混响；
- 每个场景一个情绪（落水：低沉长音 + 很轻的高音颤动；化雪：明亮的上行；告别：缓慢的主题回放）；
- 整体音量**有意做轻**，字幕和画面是主角；成片音轨平均 −20.5 dB、峰值 −6.1 dB。
- 输出 `score.wav`（不入库）→ ffmpeg 转 `score.m4a`。**我听不到**，只能查电平：每 10 秒的响度、有无静音空隙、有无削波。

## 7. 渲染（`scripts/render.sh`）

```
node scripts/scene_ranges.mjs > out/ranges.txt         # 每场的起止帧
while read id a b; do                                   # 分场景渲染（--muted，crf 18，jpeg-quality 96，concurrency 4）
  npx remotion render src/index.ts Film out/parts/$id.mp4 --frames=$a-$b --muted …
done
ffmpeg -f concat … -c copy out/video-silent.mp4          # 拼接
ffmpeg -i out/video-silent.mp4 -i score.m4a -crf 27 … dist/<名>.mp4   # 二次编码 + 合音轨
```

- 分场景渲染的好处：改一场只重渲一场（删掉 `out/parts/<id>.mp4` 再跑；`FORCE=1` 全部重来）；
- 中间文件 crf 18 ≈ 300 MB，成片 crf 27 ≈ 61 MB（`FINAL_CRF=23` 可以压得没那么狠）；
- 浏览器：环境变量 `REMOTION_BROWSER` 指向本机 Chromium `headless_shell`（沙箱里下载 Chrome 会被拦）；
- 看某一帧：`node scripts/stills.mjs Film:s4-river+9 --scale=0.5`（场景 id 前缀 + 场景内秒数；多帧要**每个都带前缀**：`Film:s3+2.8,s3+5.5`）。

## 8. 成片验收（交付前必做，结果写进 README）

1. 时长：`ffprobe`，4–5 分钟；
2. 从**成片 MP4**（不是从源码）每场抽 1–6 帧，拼联系表（`scripts/contact.py`），逐张看：风格统一、字幕在画面内（最宽一条的宽度/左右余量）、字幕没盖住角色；
3. **暖色审计**（`scripts/audit_warm.py`）：对抽帧逐像素找暖色（HSV 色相 0–70° 或 335–360°，S ≥ 0.30，V ≥ 0.30），标成洋红，人工确认只落在约定的几处（灯 + 光晕、火堆、红围巾）；
4. `npm run check` 全绿；
5. 音轨电平（平均/峰值/每 10 秒响度）；
6. README 里写“判断记录”和“已知局限”（见参考实现的 README）。

## 9. 配色规则怎么落地（参考实现）

- 全片冷色：深靛蓝夜空、白雪、蓝灰阴影；`src/palette.ts` 里**暖色只有三组**：灯（`lamp*`）、火（`fire*`）、红围巾（`scarf*`）；
- 冲突时取约定的规则，并写进 README：红棉衣 ↔ “暖色只有三处” → 棉衣画成冷靛蓝，红围巾是唯一的红；兔子的粉鼻子 → 偏紫的冷粉（色相约 300°）；皮肤 = 纸白；汽车不画（车灯是第四处暖色）；面包画成白色；
- 参考图只学画风：不照抄角色和构图（参考图是一匹马低头靠近男孩和狐狸 → 本片白鹿的几个低头镜头周围是冰窟窿、小木屋、兔子和乌龟，且是远景）。
