# 02 · 做单文件绘本网页：影片画面 + 故事全文

目标：影片只能放 3.5% 的字（40 条字幕、403 字，全文 11,356 字）。绘本网页把**全文**一页页放出来，
**每条影片字幕对应一页、一张画面**，影片里没有的章节补上同一画风的插图。最后是**一个 HTML 文件**，双击就能读，离线可用。

参考实现：`snow-lamp-film/webapp/` → `dist/snow-lamp-book.html`（99 页，3.9 MB）。通用模板在本技能的 `templates/webapp/`。

## 数据流

```
story/source.md ─────────────┐
src/timeline.json ─► scripts/storyboard_plan.mjs ─► out/storyboard_plan.json（每条字幕的取帧号）
                                                      │
Remotion: Film{subtitles:false} + Plate{which} ─► scripts/book_stills.mjs ─► out/book_img/{cue,plate,film}/*.png
                                                      │
webapp/plan.py（分页）─► webapp/out/plan.json ─► webapp/build.py ◄─ webapp/heroes.json（没有字幕的页用哪张图）
                                                      │            ◄─ webapp/{template.html,app.css,app.js}
                                                      ▼
                                             dist/<名>-book.html   ──► webapp/qa.mjs（真浏览器逐页核对 + 截图）
```

## 1. 出画面

**干净帧（不带字幕）**：给 `Film` 合成加一个 `subtitles` 参数（默认 true），取帧时传 `{subtitles:false}`。
每条字幕取**停留 70% 处**的画面（和分镜 PPT 同一帧：此时字幕已淡入、动作已展开）。再加一张**封面**：片头场景里题目还没浮现的那一刻（`s0 + 0.75 s`，题目在 0.8–2.2 s 才出现——别拿带题目的帧做封面，网页上会出现两个题目）。

**补充插图（`src/plates/Plates.tsx`）**：影片里没有的章节（影子、问号的问题、农夫伯伯的小院、雪人、古城墙、学校、大海、星星、白鹿的心事、森林比赛）用**同一套角色 + 同一套画笔**再画一批，注册成 `Plate` 合成（`which` 属性选哪幅）。
参考实现 10 幅，约 600 行：

- 外壳 `Wrap`：天空/远林/雪地 + 内容 + 飘雪 + 纸纹；`mountFade` 让山的左右边缘渐隐（山图是矩形，白天的天空上会露出边）；`FrameTrees` 做前景两侧的树影（宽度 `k≈0.66` 才刚好把树放在两边）；
- 小道具各是一个 `Art`：雪人、农家小院（青瓦白墙、烟囱、草垛、老桑树、水井、篱笆）、古城墙 + 古塔、动物剪影（狐、松鼠、猫头鹰、乌鸦）、“记忆圆窗”（讲故事的人心里的画面：学校、大海——沿用影片里“心里的家”那个圆窗的画法）、星空（190 颗星 + 银河 + 弯月 + 流星）；
- **直角要加密**：`dense(pts, step)`；
- 动物太多画不过来 → 只画剪影和成对的眼睛；
- 每画完一批先出 0.5 倍联系表看，再改（改了 3–4 轮：蝙蝠一样的猫头鹰 → 栖在树枝上的猫头鹰；像蘑菇的房子 → 加密边线后有了墙和屋顶）。

出图：`node scripts/book_stills.mjs`（`--only=plate/` 只重出补充插图）→ `out/book_img/{cue,plate,film}/…png`（1920×1080）。`FILM` 表里列“从影片里额外挑的帧”（山洞里的家、化雪的草地、小木屋门口、回家的小房间）。

## 2. 分页（`webapp/plan.py`）

输入：全文 + 每条字幕的位置。规则：

1. **一条字幕一页**：字幕在原文里的位置是“锚点”；页从**锚点所在段落的开头**开始（同一段里有两条字幕，第二页从那条字幕所在的**句子**开始）；
2. 章名要在页首：每章第一个单位是切点；章首不足 95 字、又没有锚点的小碎片并进下一页；
3. 两个锚点之间文字太长 → 按**版面行数**切开：`lines_between()` 粗估一页排版要占几行（每段 `ceil((字数+缩进)/每行字数)+0.45` 行，章首另加章名 3.4 行）；超过 `SOFT_MAX` 才切，切成 `ceil(行数/CAP)` 页，切点优先选段落边界，实在没有再选句子边界；
4. 诗、问题列表（连续几行没有空行隔开的块）整块不拆；
5. 引号：原文是 ASCII `"`，显示时按段配成弯引号 `“ ”`（`'` → `‘ ’`），**只改显示，不改字**；
6. 输出 `plan.json`，并打印每页的字数/行数/锚点，一眼能看出哪页太长或太短。

调这几个常数：`CPL`（一行字符数）、`CAP`（目标行数）、`SOFT_MAX`。参考实现：`CPL=25, CAP=13.4, SOFT_MAX=15.6` → 99 页，其中只有 2 页在 1440×900 下需要滚一点点。
> 教训：一开始按“汉字数”分页（每页 270 字），对话多的章（问号的问题）一页要滚 1000 多像素；改成按**行数**估算后，对话章自动分成更多页。

**页的两种**：有字幕的页（40 页，插图 = 那条字幕的画面，文字里把那一句标成金色，图下有“看影片里的这一幕”）；没有字幕的页（59 页，插图见下）。
一章里连续几页**共用一张插图**时，翻页只换文字、图不动（`app.js` 里 `heroKey` 相同就保留 `.pic`），读起来像“同一幅图，故事往下接着讲”。

## 3. 配图表（`webapp/heroes.json`）

```jsonc
{ "cover": {"img": "film/cover", "alt": "…"}, "end": {"img": "cue/39", "alt": "…"},
  "sections": { "第四节": [ {"img":"plate/questions","fx":0.55,"fy":0.6,"cap":"补充插图：…","alt":"…"},
                             {"img":"plate/questions","fx":0.45,"fy":0.78,"z":1.7, …}, … ] } }
```

- 按**章**列图：这一章里没有字幕的 m 页，**按顺序平均分给 L 张**（`list[k*L//m]`），页数变了不用改表；
- `fx, fy` = 想看的中心（0–1），`z` = 放大倍数：同一幅插图取不同的景（全景 → 特写），一幅图能撑 3–4 页；
- 没配的章，自动沿用上一页的画面并换个取景（构建时提示，建议补上）；
- `alt` 给读屏软件，`cap` 是图下的小字（“补充插图：…” / “影片画面：…”）。

## 4. 网页本身（`template.html` + `app.css` + `app.js`，没有任何依赖）

**结构**：封面 → 99 页（左图右文；窄屏上图下文）→ 结尾。数据在 `<script type=application/json id=book-data>`，图在 `window.__IMG`（WebP data URI）。

**版式**
- 桌面横屏：两栏等宽，图是 16:9 圆角卡片（宽度同时受可用高度限制，永远完整显示），图下一行小字 + “看影片里的这一幕”；右边是书页卡片：章名（小字章号 + 大字章名 + 金色小灯分隔线）→ 正文；
- 正文字体霞鹜文楷，`font-size = clamp(16px, min(1.7vw, 2.8vh), 30px) × 字号倍数`（随视口缩放，16:9 下每页容量一致）；行高 1.85，段首缩进 2 字，两端对齐；
- **短页自动放大**：<45 字 ×1.5，<110 字 ×1.22（绘本的感觉）；诗居中、问题列表带左边线；
- 字幕那一句用“荧光笔下半条”的金色标出（可关）；点它 = 打开影片；
- 放不下时底部渐隐，提示还能往下滑；
- 主题：`雪夜`（深靛蓝卡片、浅色字）/ `纸色`（米白卡片、深色字），默认跟随系统；**暖色只给“灯”**：金色按钮、字幕标记、章名小灯点、进度条的滑块（一盏小灯）；
- 背景有一层很轻的飘雪（canvas，64 片；尊重“减少动态效果”）。

**导航**：上一页/下一页大圆钮、进度条（章首刻度，有影片画面的章用金色刻度）、键盘 ← → PageUp/Down Home End、触屏左右滑、`#p12` 地址可直达某页、自动记住读到哪一页（localStorage，失败也能读）。

**弹层**：目录（章名 + 页码 + “影片 n 幕”）；**分镜总览**（影片里 41 个画面按场景分组，点一张跳到对应的页）；**放映**（全屏逐张放影片画面，字幕叠在底部，可自动播放）——这就是“PPT 变成网页”；设置（字号 4 档、背景、字幕标记、朗读本页、全屏）；看影片（`<video src="<名>.mp4#t=秒">`，影片放在网页旁边就能播，没有就给提示）。

**朗读**：浏览器自带的 `speechSynthesis`（zh-CN）；没有中文声音时提示，不会报错。

## 5. 打包（`webapp/build.py`）

1. 调 `plan.py` 分页，按 `heroes.json` 配图；给每页的字幕句子算出高亮区间（忽略引号和空白）；
2. **全文核对**：把所有页的文字拼起来，和 `story/source.md`（忽略引号、空白）逐字比对，不一致就报错并指出第几个字（参考实现：13,218 字符、360 个段落块、99 页，通过）；
3. 插图 → 缩到 1440 宽 → WebP（q80, method 6）→ base64。56 张共 2.4 MB；平均亮度 <50 的画面自动提亮（还没点灯的小房间）；
4. 字体：把页面上出现过的**所有字符**（含界面文字）从霞鹜文楷里裁出来（regular 313 KB，1480 字符）；标题用一个更小的 bold 子集（73 KB）；
5. 把 CSS / JS / 数据 / 图片 / 字体内联进 `template.html`，写 `dist/<名>-book.html`（3.9 MB）。

> 单引号 `‘ ’` 在霞鹜文楷里没有字形，会回退到系统字体，无碍。

## 6. 自动检查（`webapp/qa.mjs`，真浏览器里）

用 Playwright（全局装好的，`/opt/node-tools/node_modules/playwright`）+ 本机 Chromium：

1. 把 99 页逐页翻一遍，取页面上**真正显示出来的文字**拼起来，和原文（加章名）逐字比对 → 必须一致；
2. 逐页：图是否加载、有没有横向溢出、文字区是否要滚动（并列出来）；
3. 控制台不能有报错；
4. 截图：桌面 1440×900（封面、十几页、目录、分镜总览、设置、看影片、放映、纸色主题）、1920×1080、平板竖屏 820×1180、手机竖屏 390×844（DPR 2）、手机横屏 844×390；`--all` 再把每一页存成 1280×720 缩略图，拼联系表人工看版式。

人工看图时盯这几类：图和文是否对得上、取景是否裁到了要看的东西、字是否太大/太小、哪页空得难看、封面有没有重复的题目、暗图是否一团黑。

## 7. 换一个故事要改什么

1. `story/source.md`（章节用 `## 标题`；标题形如 `第三节　名字` / `开头　…` / `尾声　…`，`plan.py` 的正则要对得上）；
2. `src/timeline.json` + 场景（见 01）；
3. `webapp/heroes.json`（按章配图）；有影片没覆盖的章，就在 `Plates.tsx` 里补几幅；
4. `build.py` 里的 `filmFile`（影片文件名）、封面/结尾；`template.html` 的标题；`app.js` 封面副标题；
5. 跑 `npm run book:stills && npm run book && npm run book:qa`，看联系表，再调 `CPL/CAP/heroes`。

## 8. 设计决定（为什么这样做）

- **单文件**：用户要“能直接双击打开、能下载走”的东西；所以图用 WebP data URI、字体用 base64、不依赖 CDN。3.9 MB 完全可以（再大就降图片宽度/质量，`build.py` 顶部的 `WIDTH/QUALITY`）；
- **一页一画面**：和分镜 PPT 一一对应，孩子和家长能把“影片里那一幕”找到书里那一页（反过来也行）；
- **字大 + 短页**：6–8 岁识字阶段，一页别放太多；字号可调；
- **不加拼音**：自动注音在多音字上会错（“得、着、了、地”…），给识字的孩子一个错的拼音比没有更糟；要做就接一份人工校对过的注音表；
- **不依赖外部服务**：朗读用浏览器自带的，视频是本地文件。
