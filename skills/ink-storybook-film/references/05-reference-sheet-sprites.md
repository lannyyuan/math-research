# 05 · 用“角色设定图 + 封面”做成片（纸偶 + 水彩背景的做法）

适用：用户给了**角色设定图**（正面 + 侧面）和**封面**，要求“造型、配色、比例以它为准”，英文/任意语言字幕，3~5 分钟。
参考实现：`lighthouse-light-film/`（《The Lighthouse Light》，4:38）。

## 1. 为什么不重绘角色
设定图是最强的约束。重绘（矢量/SVG）很难和它“对得上”。做法：**把设定图抠成透明 PNG 精灵**，只让它们做“轻微动作”（呼吸、晃动、走路颠簸、整体平移/旋转），背景自己画成同一画风。

抠图要点（`scripts/extract_sprites.py`）：
1. 先量出纸张底色，用 **Lab 色差 ΔE** 分割（比阈值抠色好得多）；形态学闭运算 + 条件填洞（只填被前景包围的小洞）。
2. 相邻角色的碎边用 `EXCLUDE` 矩形手动排除；边缘做软 alpha + 颜色解混（去掉白边）。
3. 锚点放在**脚底中心**（`sprites.json` 记 w/h/ax/ay），所有场景按“脚踩的位置”摆放。
4. 设定图里没有的状态，用**图层**解决，不要改原图：
   - 头饰（棒球帽 / 毛线帽 / 光头）：把帽子像素单独存一层，露出的头顶用水彩补头发；各层画布大小和锚点相同，叠放自然对上；
   - 眼睛亮 / 灭：再出一张“熄灭版”，用 `layers=[off, on]` + 各层不透明度叠化，眼睛处叠一团光晕；
   - 只露头的版本（刺猬从落叶堆里探出来）：同画布，下半截 alpha 渐隐。
5. 前后一致的逻辑**只写在一个组件里**（`cast.tsx` 的 `<Bud head pocket>`、`<Bolts eyes>`），场景里只传状态，不要各场景自己拼图层。

## 2. 背景：自己的水彩笔刷 + 视差分层
- `pt.py`：float32 RGBA 画布；`wash`（不规则边缘 + 边缘积色 + 颗粒的水彩色块）、`ink`（可变粗细、两头收尖的墨线）、`hatch`（排线）、`glow`、fbm 噪声。折线轮廓用 `smooth=False`，否则尖角会打圈。
- 每个场景 2~3 层（远景 jpg / 近景 png），宽 2900 或 2400；角色站在近景层上。夜景 = 同一套白雪调色盘 + `grade()`（整体压向蓝灰），**不要**用整屏灰罩（雪会发脏）。
- 室内：窗外用小画布单独画天空/海再贴进去（`sea()` 是整幅宽度的，直接画会铺满整面墙）。
- 暖色政策：白天/室内全用冷色；暖色只在 光柱、港口和船上的灯、灯塔灯室里。农舍的窗、床头灯用 `CoolGlow/LitWindow`（冷白）。**注意**：墙是白的时候，冷白光“屏幕混合”看不出来——要把墙先压暗（`grade('night')`）。

## 3. 镜头与动作（Remotion）
- `Stage/Layer`：视差镜头，只有慢推慢移；`Layer` 里按图的实际宽高**钳制平移量**（`w/h` 参数），镜头永远不会摇出图边（边缘露空 = 穿帮）。镜头中心 x 的有效范围是 `[960, 图宽-960]`（z=1 时）。
- 动作和字幕对齐：`cuesOf(sceneId)` 返回每条字幕在场景内的出现时间，动作用 `track(t, [[秒, 值],…])` 分段缓动。字幕时间改了，动作自动跟着走。
- 镜头切换只用**慢叠化**（`Shot from/to fade`），没有快切、没有花哨转场。
- 字幕占画面底部约 y>856；角色的**脚**尽量在 y≈850~900，水里/悬崖边的关键动作用镜头 y 偏移把它推到字幕上方。
- 躺下/爬：把侧面精灵绕脚底旋转 ±90°（头朝右 = 顺时针 90°，背包会自然朝上）；掉进水里：`clipBottom` 藏住下半身 + 窟窿前沿图层盖在腰上。

## 4. 字幕（只许用原文里的句子）
- `timeline.json` 里每条字幕必须是原文的**连续片段**（`check-subtitles.mjs` 用规整后的子串匹配；`---` 之后的统计附录不算故事）。要缩短就截取，不要改写。
- 停留 = 1.3 s + 0.55 s × 词数（+0.3 s 余量），≤ 2 行，行宽 ≤ 38 字符；`check_subtitle_fit.py` 用真字体量宽度（woff2 → `fontTools` 转 ttf → PIL 测）。
- 画面里的文字（站牌、告示）也用故事原句，用同一字体，贴在世界坐标里随镜头走。

## 5. 验收
- 联系表（`scripts/sheet.py`）看每个场景的关键帧：角色是否和设定图一致、头饰/眼睛/灯的状态是否前后一致、字幕是否出框。
- 暖色审计（`templates/film-tools/audit_warm_nochars.py`）：`Film` 加 `chars=false` 只出背景和光，逐帧找暖色像素（HSV），洋红标出来看是不是只在允许的位置。
- 成片用 ffmpeg 按字幕中点抽帧，再看一遍。

## 6. 踩过的坑
- `house()` 里“两扇窗 + 门”会重叠（第二扇窗正好在门上）→ 窗 0.17/0.49，门 0.30。
- `snow_ground` 的 `bottom_y` 必须大于坡顶最低点 +60，否则随机范围反了。
- 精灵里的子元素（Glow）在 `scale(-1,1)` 翻转的父级里也会翻转，要按“翻转后的坐标”摆。
- `useCam` 的时间是**场景内**秒数；`Shot` 子镜头里用同一个时间轴即可。
- 配乐用 numpy 合成：音乐盒 = 基音 + 非整数倍泛音各自指数衰减；铺底 = 两条略走音的正弦；风/引擎 = 一阶滤波噪声；母带用几条延时 + `tanh` 限幅。
