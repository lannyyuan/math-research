# 《雪地里的那盏灯》动画短片

给 6～8 岁、正在学认字的孩子看的 4 分多钟水彩动画。成片和可以重新渲染的源工程都在这个文件夹里。

| | |
|---|---|
| **成片** | [`dist/snow-lamp.mp4`](dist/snow-lamp.mp4)（1920×1080，30 fps，H.264 + AAC，**4 分 50.5 秒**，61 MB） |
| 技术方案 | [Remotion](https://www.remotion.dev)（React + SVG）。人物、墨线、水彩滤镜全部是代码画的；大块的天空/树林/雪地先烘焙成图片 |
| 字体 | 霞鹜文楷（LXGW WenKai，SIL OFL 1.1），只保留字幕用到的字，37 KB（`public/fonts/`，附 OFL.txt） |
| 配乐 | 自己合成（`scripts/make_music.py`，纯 numpy，无采样、无外部素材） |
| 图像 | 没有任何外部图片。参考图只学了画风，没有用它的角色和构图 |

## 怎么重新渲染

需要：Node ≥ 20、ffmpeg、一个 Chromium（本机的 `headless_shell` 即可，用环境变量 `REMOTION_BROWSER` 指定；脚本里默认是 `/opt/pw-browsers/...`）。

```bash
cd snow-lamp-film
npm ci
npm run check      # 检查字幕：每条是不是原文片段、停留时间够不够、总时长在不在 4~5 分钟
npm run studio     # 打开 Remotion Studio 预览（带配乐）
npm run render     # 分场景渲染 → 拼接 → 压成片并合上配乐 → dist/snow-lamp.mp4（4 核约 35 分钟）
```

* 分场景的中间文件用 crf 18（约 300 MB，在 `out/parts/`，不提交），成片再用 crf 27 压到 61 MB（`FINAL_CRF=23 npm run render` 可以压得没那么狠）。
* 只想重渲某一场：删掉 `out/parts/<场景>.mp4` 再 `npm run render`（已渲好的场景会跳过）；`FORCE=1 npm run render` 全部重来。
* 看某一帧：`node scripts/stills.mjs Film:s4-river+9 --scale=0.5`（场景 id 前缀 + 场景内秒数），图在 `out/stills/`。
* 改了 `src/bake/assets.tsx`：`npm run bake` 重新烘焙 `public/baked/`（已提交，不改就不用跑）。
* 改了配乐：`npm run music`；改了字幕用字：`npm run check`（生成 `story/subtitle-chars.txt`）然后 `npm run font`（需要 `pip install -r requirements.txt`）。

```
public/baked|fonts|audio 烘焙图、字幕字体、配乐

```

## 字幕

* **只用原文的句子**：每条字幕都是 `story/source.md` 里的一段连续文字（可以只取半句，首尾的逗号可去掉；引号、空白忽略）。`npm run check` 会逐条验证，**没有一条是新造的句子**。全片共 40 条字幕，用到 160 个不同的汉字，都来自原文。
* **停留时间**：每条至少 `1.6 秒 + 0.30 秒 × 汉字数`（标点按 0.25 个字），再加 0.2 秒余量。例如 8 个字的一条停 4.2 秒、16 个字的停 6.6 秒——最快的一条也不到每秒 2.6 个字，是按“刚学认字、一个字一个字地读”的速度算的。每条之间至少留 0.3 秒，淡入淡出各 0.35 秒。
* **字号**：单行 76 px（1080p 画面高度的 7%），两行时 64 px；字体是楷体系的霞鹜文楷，笔画接近教材里的写法；深靛蓝半透明底，雪地上也看得清。
* 为了让字幕之外还有安静的画面，全片约 69% 的时间有字幕，其余是只有画面和音乐的“留白”。

## 画风是怎么做出来的

* **松快的墨线**（`src/art/ink.ts`）：每一笔都是一个“变宽多边形”——两端收细、中间时粗时细、偶尔“压笔”变粗、下行笔画略重；线会有缓慢的手抖，偶尔断笔；再叠上一两遍更细更淡、偏离轮廓、两头出头的**起稿辅助线**，大块的形体上还有辅助圆。线条边缘用一个很小的位移滤镜做出墨水洇在纸上的毛糙。
* **透明水彩**（`src/art/ArtView.tsx`）：颜色是单独一层，**整体向右下偏移几个像素，溢出线外**；边缘用湍流位移抖动、颗粒调制、边缘积色（比中间深一点）；阴影是另一层很淡的蓝灰（`#6b80b4` 透明度 0.3~0.4），颗粒更重。
* **纸张**：全片叠一层 overlay 的纸纹（细颗粒 + 纤维 + 四角轻轻压暗）。
* **大面积的水彩层**（天空、剪影树林、雪地、山）在 `src/bake/assets.tsx` 里用 SVG 滤镜画好，渲成图片，影片里只做平移/缩放（视差）。
* **镜头**：全是缓慢的推、拉、摇（正弦缓入缓出）；没有快切，场景之间只有一小段明暗过渡；角色只做呼吸、点头、摆耳朵、走路时的摆腿。
* **雪**：三层雪花（远小慢、近大快），全片都在下，**到“冰雪化开”那一场逐渐停下，之后不再下雪**（山顶的雪地是冬天留下的；最后一场窗外是春雨）。

## 几个自己做的判断

1. **“暖色只出现在灯、火堆、红围巾”与“红棉衣”冲突** → 取前者。小石头的棉衣画成冷色的靛蓝，**红围巾是他身上唯一的红**。想改回红棉衣，只要改 `src/palette.ts` 里的 `jacket`。
2. **兔子的粉鼻子** → 用偏紫的冷粉（`#cfa6cf`，色相约 300°，不在暖色范围内），只有鼻尖和耳朵里一点点。
3. **皮肤** → 画成纸白（水彩常见的“留白”），带一点蓝灰阴影，不用肤色。
4. **汽车** → 不画。车灯会是第四处暖色，所以爸爸妈妈是走上山来的。
5. **面包** → 画成白色的小圆面包（冷色）。
6. **灯在每一场都出现**：山顶远处的灯（第 1~4、6、7 场，越走越近）、山洞口外的灯（第 5 场）、心里窗边的灯（第 5 场）、壳上路线尽头的灯（第 9 场）、小木屋窗里的老油灯（第 8、9 场）、窗边的小灯和窗外山顶的灯（第 10 场）。灯是全片唯一带光晕和星芒、会一闪一闪的暖色；火堆只有很淡的暖光。
7. **白鹿**：身体圆润、脖子有一圈蓬松的颈毛、耳朵大而圆、尾巴短短上翘、蹄是深蓝灰；没有鬃毛、没有长尾、没有翅膀；**鹿角是两棵小树**（程序生成的分枝，枝头顶着雪，春天长出新叶）。
8. **不复制参考图**：参考图是一匹马低头靠近男孩和狐狸。这里白鹿低头的几个镜头，周围是冰窟窿、小木屋、兔子和乌龟，镜头也是远景。
9. **落水和小狼两段的“紧张但不吓人”**：用慢慢推近的镜头、屏住呼吸的安静、低沉的长音和很轻的高音颤动来做紧张；落水时全程是柔和的蓝，小石头一直把头露在水面上、高举着手，兔子拉着红围巾；狼是又小又冷的小狼，狼妈妈眼神温柔，没有露牙、没有突然的动作。

## 抽查结果（交付前）

* **时长**：`dist/snow-lamp.mp4` = 4:50.5（要求 4~5 分钟）。
* **关键帧**：直接从成片 MP4 里每个场景抽 1~6 帧（共 42 帧）人工看过：画风统一；字幕都在画面内（最宽的一条是 18 个字，连底约 1558 px，在 1920 px 宽的画面里左右各留 180 px 以上；单行底边距画面底 74 px、两行 50 px）；字幕没有盖住角色的脚。
* **暖色审计**（`scripts/audit_warm.py`）：对这 42 帧逐像素找暖色（色相 0~70° 或 335~360°、饱和度 ≥ 0.30、亮度 ≥ 0.30）并标成洋红。暖色区域只落在：灯（含灯光晕）、火堆、小石头的红围巾（含兔子拉着的那段围巾）。没有发现别处的暖色。（第 10 场卧床镜头左上角那几小块是窗边灯的光晕。）
* **字幕**：`npm run check` 全部通过。

## 已知的局限

* 角色是“纸偶”式的：只有轻微的呼吸、点头、摆耳、走路摆腿，转身是翻面；没有口型。
* 兔子/小狼/白鹿等大多是侧面；拥抱、拉勾、下鹿这些动作用的是简化的姿势，在远景里读得出来，推近看就比较粗。
* 配乐是合成的（音乐盒/钟琴、长音、拨弦、风/火/水/雨的底噪），我没法“听”它，只做了电平的检查（成片音轨平均 −20.5 dB、最大 −6.1 dB，每 10 秒的响度都在 −19~−26 dBFS 之间，没有静音空隙和削波）；音量有意做得很轻，字幕和画面是主角。
* 渲染环境是 Linux 无显卡的容器，用软件光栅化，4 核约 40 分钟。
