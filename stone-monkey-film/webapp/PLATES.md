# 补充插图清单（plate/*）

《小石猴点灯》绘本网页里，第七分及之后的各章、四个增补用“补充插图”配图。共 **16** 个 key，文件放在 `out/book_img/plate/<名字>.png`（16:9，建议 1920×1080；没有图时 `npm run book` 会自动生成“待配图：key”的水墨渐变占位图，不影响阅读和 QA）。

**每个 key 都是“现成背景板 + 现成人物精灵”拼出来的一个小场景**（背景板在 `public/bg/`，人物精灵在 `public/sprites/`），不是重新画新场景：每条写了 `base:`（背景板）和 `chars:`（人物精灵），画面里只有“几个人 + 一两个道具”，道具（灯笼、火盆、船、纸鸢、小石牌……）用简单形状画。人物的年龄变化（少年、成年、老年石娃）统一用同一个石娃造型。

同一个 key 在不同页取不同的局部（`webapp/heroes.json` 里的 `fx / fy / z`：取景中心 0~1、放大倍数），所以**构图要把“取景”一栏写的东西放在对应的位置**。其中 `kitchen`（灶间）和 `village_day`（村子白天）是主力，被很多章共用，所以做成“全景里有好几块小场景”。第一~第六分用影片帧 `cue/01`~`cue/40`（见 heroes.json 顶部说明），不在这里。

## 统一约定

- 画风和影片一致（水墨水彩、宣纸纹理）；色调克制：夜色靛蓝/灰蓝为底（#121A2E / #1E2A44 / #5A6B86），纸白 #EFE8D8；**暖色只给“灯”**（灯笼、油灯、火盆、天灯：灰金 #cfc29a / #F3D98A）、奶奶的红头绳、小姑娘的红裙（朱砂 #B8382E）。
- 时间线：**第七分（主城见闻）发生在点灯之前**，用 `*_night` 背景；**第八分起在灯亮之后**，用 `*_lit` / `*_day` 背景。
- 背景板文件名按 `public/bg/` 现有的写；`kitchen`、`hall_king`、`lamp_sky`、`village_dawn` 等名字按影片里用的背景板（若文件名不同，以影片里的为准）。
- 画面里不要放字（网页上图下面有小字图注）。

### 1. `plate/river_night` — 夜里的江边

- base: `river_night`（river_far / mid / near_night + river_bridge_low_night）
- chars: `shiwa_side`（坐姿）、`houzi_side`（蹲在他膝头）
- **光线/时间**：夜，无月，星稀（灯亮之前）
- **画面**：江岸夜景，小桥（`river_bridge_low_night`）横在中景。左下三分之一：石娃坐在岸边石头上，龟甲蹲在他膝头，两人手里各一小块咸菜（几笔简单的小方块即可）；脚边一只小布袋。不加别的人物和道具。
- **用在**：
  - 增补一 第 1 张（取景 `wide`，章首）：夜里的江边，新搭的桥，他和龟甲坐在柳树下
  - 增补一 第 2 张（取景 `close`，从 #5 起）：把咸菜掰成两半，两人分着吃
- **取景（构图时把这些放在对应位置）**：
  - `wide`（fx 0.5，fy 0.55，z 1）：整幅：夜里的江岸与小桥
  - `close`（fx 0.28，fy 0.72，z 1.9）：左下：石娃和龟甲分咸菜

### 2. `plate/hill_night` — 夜里山路上的老人

- base: `hill_night`（hill_far / mid / near_night）
- chars: `shiwa_side`、`houzi_side`（肩上）、`herder_front`（当作砍木老人，放大一点）
- **光线/时间**：夜，灰蓝（灯亮之前）
- **画面**：山路夜景。左三分之一：石娃走在上山的路上，龟甲在肩上，仰头看老人；右三分之一：老人（牧人精灵充当）站在路边，手里举一把老刀（用简单的灰色长条加一点高光画）。不加别的。
- **用在**：
  - 增补二 第 1 张（取景 `wide`，章首）：翻第二道岭，遇见砍木的老人
  - 增补二 第 2 张（取景 `knife`，从 #7 起）：“铁要反复打，才成器。人也是这样。”
- **取景（构图时把这些放在对应位置）**：
  - `wide`（fx 0.5，fy 0.55，z 1）：整幅：山路、老人与石娃
  - `knife`（fx 0.72，fy 0.62，z 1.8）：右侧：老人和他手里的刀

### 3. `plate/stone_city` — 地下的石城

- base: `gate_night`（gate_far / mid / near_night，整体压暗一档，当作地下石城门）
- chars: `shiwa_side`、`houzi_side`、`herder_front`（守门老人，白发可不改）、`girl_front`（小姑娘）、`villagers`（3~4 个压成深色剪影的“影子”）
- **光线/时间**：黑暗，冷青灰；只有守门老人的灯和石娃袋里的一点光是暖色
- **画面**：石城门居中。左三分之一：石娃和龟甲，手里一点微光（用 `pearl` 精灵缩小代替），头顶上画一个不规则的黑色缺口（洞口）；中间：城门口站着、蹲着几个深色人影（推石、挑水、跪坐，用 villagers 压暗）；右三分之一：守门老人提一盏小灯（简单圆形 + 暖光）拦在门口，右下角小姑娘伸手递一颗小石子（一个小灰点）。
- **用在**：
  - 增补三 第 1 张（取景 `left`，章首）：脚下塌了，他落进一个黑洞
  - 增补三 第 2 张（取景 `wide`，从 地下2 起）：石城里住着影子般的人
  - 增补三 第 3 张（取景 `gate`，从 地下3 起）：守门的老人让开路，小姑娘塞给他一颗小石子
- **取景（构图时把这些放在对应位置）**：
  - `left`（fx 0.2，fy 0.5，z 1.5）：左侧：洞口、石娃和龟甲的一点光
  - `wide`（fx 0.5，fy 0.55，z 1）：整幅：石城与门口的影子
  - `gate`（fx 0.78，fy 0.62，z 1.6）：右侧：守门老人与小姑娘

### 4. `plate/village_lamps` — 家家点灯的小村（夜）

- base: `village_night`（village_far / mid / near_night；亮灯的版本可用 village_*_lit 的窗光）
- chars: `nainai_front_red`（右边门口）、`shiwa_side`（左边，远小）、`villagers`（2~3 个，手里提灯）
- **光线/时间**：夜，天还是黑的，只有灯
- **画面**：夜里的小村，家家门口挂着一盏灯（简单的暖黄圆点 + 光晕，连成一条弯弯的光带）。左边远处石娃背着小布袋往回走；右边一户门口站着奶奶，窗里透出暖光；中间两三个村民提灯。窗外是黑色夜空。
- **用在**：
  - 增补四 第 1 张（取景 `wide`，章首）：他回到村里，家家门口都点着灯
  - 增补四 第 2 张（取景 `door`，从 #4 起）：奶奶摸着他的头：“你学会了两件事。”
  - 第十六分 第 3 张（取景 `wide`，从 145 起）：夜里，两人坐在屋檐下说闲话，牧人讲起一个传说
  - 第二十分 第 4 张（取景 `wide`，从 183 起）：那些年边境不宁，临行前夜，家家都来送
  - 第二十分 第 6 张（取景 `window`，从 186 起）：抬头看看窗外——只要有人肯举一盏灯，夜便不会太黑
- **取景（构图时把这些放在对应位置）**：
  - `wide`（fx 0.5，fy 0.55，z 1）：整幅：一条光带般的村路
  - `door`（fx 0.8，fy 0.58，z 1.8）：右侧：奶奶站着的门口
  - `window`（fx 0.82，fy 0.45，z 2.2）：右侧：亮着灯的窗与窗外的夜空（特写）

### 5. `plate/gate_night` — 主城的街口、市集与擂台（夜）

- base: `gate_night`（gate_far / mid / near_night）
- chars: `children`（小豆，1 个）、`guard_front`（兼作壮族，另 2 个站城门口）、`villagers`（3 个）、`shiwa_side` + `houzi_side`
- **光线/时间**：灯亮之前：深蓝夜色，灯笼和摊上的灯是暖色
- **画面**：以城门为背景。左：街口一口老井（用简单圆圈 + 一只小木桶），小豆在井边打水；中：城门两侧各站一个卫士，门前两张简单的摊桌（矩形 + 几个小圆篮子），后面站着 2~3 个村民；右：一个矮矮的台子（简单矩形）当擂台，台上壮族（卫士精灵放大）举着一根粗棍，台下两个村民看。石娃和龟甲站在画面中下，小小的。挂几盏灯笼（暖色圆点）即可，不画一整个集市。
- **用在**：
  - 第七分 第 1 张（取景 `wide`，章首）：主城的长街，街口的老井，井边的小男孩
  - 第七分 第 4 张（取景 `stalls`，从 50 起）：城里的市集，卖米的、卖菜的、卖鱼的、卖布的一字排开

  - 第七分 第 6 张（取景 `gate`，从 53 起）：宫门又高又厚，卫士拦路
- **取景（构图时把这些放在对应位置）**：

  - `stalls`（fx 0.45，fy 0.68，z 1.5）：中间：门前的摊桌与村民
  - `arena`（fx 0.82，fy 0.5，z 1.7）：右侧：擂台与壮族
  - `gate`（fx 0.5，fy 0.38，z 1.7）：中上：城门与门口的卫士（宫门）

## 改图/换取景

- 画好后直接放进 `out/book_img/plate/`，重新 `npm run book` 即可；不用改 heroes.json。
- 觉得某个取景不对，改 `webapp/heroes.json` 里那一项的 `fx / fy / z`；要换成别的 key 就改 `img`。
- 某块东西的位置和上面写的不一样，也只要改对应的 `fx / fy / z`。
