# 背景画板与角色清单（《小石猴点灯》动画短片）

这是给“画板/角色”分工的统一说明。所有画都用同一套水墨水彩笔法（`pt.py` + `cn.py`），风格基准是 `ref/cover.png`（封面）和已经画好的参照画板 `bg_village.py`（输出 `public/bg/village_*`，成片里的样子见 `out/stills/Film-s1_*.png`）。

## 0. 全局规则

**坐标与图层**
- 世界坐标系：画面 1920×1080；一块画板通常是 2900×1080（镜头在里面平移/推拉），也有更宽/更高的（见各板）。原点左上角，y 向下。
- **地面线（角色脚底）y = 832**。角色是“纸偶”，脚底踩在 y=832 附近；画板的地面/甲板/地板/路面的上沿要落在 y≈825~840。
- **字幕带**：成片的画面底部（屏幕 y>845）会盖一条半透明墨色带。画板里 y>845 的地方只放“地面质感/水/雪/草/远景延伸”，不要放任何重要内容。
- **留白**：每个镜头至少 1/3 是空的天空/水面/雪地。构图要空、静，比封面更空。
- 角色尺寸（世界像素）：石娃身高≈320（头顶 y≈510），奶奶≈330，成年人≈430~480，龟甲（石猴）只有≈45（手掌大）。**门、桌子、台阶、栏杆要按这个比例画**：供人进出的门高 ≥ 340，桌面高≈110（桌面 y≈720）。
- 分层：`<name>_far`（不透明 JPG：天空+远景）、`<name>_mid`（带透明 PNG：中景）、`<name>_near`（带透明 PNG：近景+地面）。视差比例影片里是 far 0.3~0.35 / mid 0.6~0.65 / near 1.0。室内/小场景可以只有 far + near。
- 每块画板由 `save_plate(name, canvas, variants=('night','lit'), gain=…, keep=…)`（`ccommon.py`）保存，它会自动做：水彩化收尾（颗粒/积色/湿边）、夜色版、光照版，并把条目写进 `public/bg/manifest.json`。**夜色版**就是影片里最常看到的样子（靛蓝 + 灰蓝 + 纸白 + 墨），**光照版**是宝珠的光照到的地方显现出来的柔和自然色（灰绿、土黄、石灰色、降了饱和度）。所以：先用“中性淡彩”（`cn.N` 调色盘）把明暗层次画好，夜色/光照两版都靠 `grade.py` 自动得到；`gain` 越小夜色越暗（远景天空一般 0.6，近景地面 0.55，室内可以 0.7~0.8）。需要“白天/晨光”版的板子会在各板里单独写明。
- 看图：`python3 composite.py <name> night,lit 0.5` 把 far/mid/near 叠起来存预览（路径会打印），用 Read 看；再裁 1:1 的局部检查笔触。

**色彩规则（很重要，任务书硬性规定）**
- 夜色色板：深夜 #121A2E、靛蓝 #1E2A44、灰蓝 #5A6B86、纸白 #EFE8D8（雪和雾）、墨 #2A2622。
- 暖色只允许出现在：宝珠的光、龟甲的眼睛、篝火和火种（#E8873A）、奶奶的红头绳和红布包（#B8382E）、小姑娘的红裙（面积很小）。**其他一切，包括金鼓、国王的衣服、神的金光、窗里的光、屋顶的草、灯笼，都要降低饱和度，往灰金/土黄/灰蓝走，不能抢光源。窗里的光和灯一律画成纸白/冷白，不要暖黄。**
- 中性淡彩里别用高饱和色；`cn.N` 里的颜色已经是降过饱和度的，直接用或在它们之间混合。

**笔法**（见 `cn.py`）：松动的墨线（`brush`：宽度渐变、飞白 `dry`、起收笔收尖）、短促的皴擦/草丛/点苔（`flicks`）、透明水彩色块（`wash`：边缘不规则、边缘积色）、山（`mountain`）、雾（`mist`）、树（`pine`/`old_tree`/`willow`/`bamboo`）、石（`rock`）、地（`ground_strip`）、水（`water`）、茅屋（`thatch_hut`）。允许轮廓不闭合，偶尔露出一两根铅笔起稿线（淡灰细线）；色块和墨线可以略微错开。

**不许**：动漫大眼、3D 质感、渐变霓虹、厚涂油画风；欧式建筑（城堡尖塔、哥特式）；孙悟空的符号（金箍、虎皮裙、筋斗云）；桃子特写。建筑一律中式（青砖、灰瓦、飞檐、木柱、斗拱的简化）。

**文件约定**：每块板一个脚本 `scripts/paint/bg_<name>.py`（参考 `bg_village.py` 开头的写法：`from ccommon import *`）。**不要修改**共用文件 `pt.py / cn.py / ccommon.py / grade.py / composite.py / bg_village.py / bg_title.py`；需要新工具就写在你自己的模块里（如 `cn_water.py`、`cn_arch.py`、`cn_people.py`），在你的脚本里 `from cn_xxx import *`。不要运行 Remotion（CPU 留给渲染），不要 git commit/push。

## 1. 水（Agent W）

### river —— 江边断桥（S2 河边搭桥）
- 尺寸 **2900×1500**（镜头会向下摇去看水里），分层 far/mid/near。地面线 y=832。
- 构图：左岸（x<1080）和右岸（x>1820）是土石岸，岸顶 y≈832（角色站的地方），岸壁向下斜落到水面；中间的豁口 x 1080~1820，**水面很深，在 y≈1180~1500**（桥高高架在水上），水又急又深：横向的水纹笔触、白色浪花线、一根顺水漂的枯木（x≈1400,y≈1300）。远景：山、雾（山脊在 y 500~700）。far 层要铺满 1500 高（下半部分是远处的水面和雾）。
- 岸上：左岸 x≈430 一棵柳树（树脚 y≈832，高≈420）、x≈160 一丛竹子；右岸 x≈2480 柳树、x≈2720 竹丛；**右岸 x 1900~2300 堆着竹子、木板、粗绳和几件工具，竹下冒出几根笋**（静态画在 near 层里：靠在一起的竹竿、叠放的木板、一圈粗绳、锯、斧；笋是几根尖尖的小褐色竹笋）。
- 另外三层桥（单独的 PNG 图层，带透明，尺寸和 river 一样 2900×1500，同样的变体，`save_plate` 名分别为 `river_bridge_broken`、`river_bridge_low`、`river_bridge_high`，只画桥）：桥横跨 x 1080~1820，桥面 y≈832，桥高 ≈ 水面以上很多：
  - broken：左右两头各留一段桥板（左 x1080~1290、右 x1610~1820，板条断口参差），中间豁口里只有**两根粗绳**从两头的桩子上垂下来、挂在半空（微微下垂的弧线，各挂着一两块断板），桥墩的竹桩歪斜/残缺；
  - low：小桥修好了——一整排木板铺在竹竿做的梁上（竹梁两头架在岸上），用绳扎牢（可见绳结），两侧一道低低的绳栏；下面是几对竹支脚插到水里；
  - high：加高一层——桥面仍在 y≈832（角色站的高度不变），但桥墩/支架高大得多（竹木支架一层叠一层，一直下到水面，有交叉斜撑），桥两侧加了竹栏杆（立柱+横杆+斜撑）。
  桥是水墨风的竹木：竹是青灰、木板是土黄灰，绳是浅灰褐。

### shore —— 东海边（S3 开头）
- 尺寸 2900×1080，far/mid/near。
- 构图：左半是沙滩（x 0~1450，地面线 y=832，沙滩上有几块黑礁石、一点海藻和贝壳），**从 x=1450 起有一条贴着海面的“干路”**（一条窄窄的沙堤/石板路，y≈832，一直延伸到右边缘 x=2900，宽约 36px 的路面，两侧湿润发亮）；路的**后面**是黑色的海（地平线 y≈610，海面上横向的浪纹和白色浪花线，没有帆没有舟），远处 x≈2300 一个黑色的小岛（上面一两棵歪树）；路的**前面**（y 850~1080）是近处的海水（深色，大浪纹，浪花）。天空：无月，星稀，浓云；海天交界处一线淡淡的雾。
- 额外一层 `shore_water_cover`（2900×1080，带透明）：覆盖干路的海水——一条横向的水带（x 1400~2900，y≈790~885），浪头起伏、白色泡沫，盖住路面（这样一开始看不到路），影片里会让它慢慢分开/淡出，露出下面的路。同样的变体。

### palace —— 海底宫殿外景（S3）
- 尺寸 2900×1080，far/mid/near。地面线 y=832（海底沙地）。
- far：深蓝灰绿的水体渐变，顶部有几道淡淡的光柱斜射下来，悬浮的细粒；远处珊瑚岩的轮廓和缓缓的水雾。mid：**宫殿正面，中心 x≈1900，宽≈900，高≈560（顶在 y≈270）**：贝壳和彩石搭的中式宫门——台基、两层屋檐飞翘、拱门（门宽 220×高 330，门洞在 x≈1900，门板是珍珠白的贝壳片镶嵌），屋面和墙是一片片贝壳/彩石（珍珠白、灰粉、土黄、石板蓝——全部降低饱和度，灰灰的珠光）；周围珊瑚枝、海草（静态，画成摇曳的姿态）、几个发白的光亮点（窗里的光是纸白，不是暖色）。near：海底地面（沙、碎石、贝壳、水纹的光斑），前景几丛海草。门前台阶要有一块空地让角色站（x 1400~1750）。

### hall_sea —— 海底宫殿内景（S3：老龙）
- 尺寸 2400×1080，far + near。地面线 y=832。
- far：大殿的后墙——高大的贝壳拱门、半透明的珊瑚屏风、从上面透下来的珠白的光；near：地面（珍珠母贝镶嵌的地板，隐约倒影）、左右两根高大的珊瑚柱（x≈130 和 x≈2270，框住画面）、**中间偏右 x≈1500 一个低低的圆形珊瑚台**（台面 y≈832，直径 520，老龙盘在上面，老龙精灵约 480×1.3 高，所以台后要留出高高的空墙）。整体很亮（“宫里很亮”）但是色调是冷灰蓝+珠光，不要暖。

### spring —— 压着泉眼的青石（S3）
- 尺寸 2900×1080，far/near。地面线 y=832。
- 海底宫殿下面的灰暗海底：干枯发灰的海草、几条病恹恹的小鱼侧躺着（很小，别吓人）、碎石。**x≈1500 是青石的位置**（青石是单独的精灵，会在这里；板上这个位置画成地面，石头周围一圈湿暗的泥）。**x≈1760~1800 地面上露出一根断木的断头**（粗木桩，长≈90，斜插），断木旁 x≈1830 有一个**小孔**（黑色，直径≈40）。
- 额外一层 `spring_clear`（带透明，2900×1080）：撬开石头后涌出的清水——x 1380~2000 的一汪清得像镜子的水（浅色、带涟漪和反光、淡淡的蓝灰绿），要有泉眼冒水的涟漪中心在 x≈1500,y≈832；影片里会淡入。
- 道具（单独的 PNG，放进 `public/sprites/`，登记进 `public/sprites/sprites.json`，写法见 `scripts/extract_sprites.py` 的 meta：`w,h,ax,ay` 其中 ax,ay 是脚底/底边中点锚点；再运行 `python3 -I scripts/make_night.py` 生成夜色版）：`boulder`（青石：比石娃还高，高≈400 宽≈520，青灰色，表面有水草苔痕和皴擦，底边平，锚点底边中点）、`lever`（长木棍：竖直，高 700 宽 36，一头略粗，锚点底端中点）、`flat_stone`（扁石：宽 160 高 50）。

## 2. 山与室内（Agent M）

### hill —— 山边小路（S4 开头：帮老奶奶捆柴）

- 夜里的山坡小路：远处层层的山和雾；中景一片松林和灌木；近景是一条小路（土路，略有起伏），路边石头；**x 1380~1700 留一块空地**（老奶奶坐在路边的石头旁，那儿有一块平的大石 x≈1650，宽 260，顶 y≈760）；左右两边有近景的松树/岩石框住（x≈150 和 x≈2700）。路面两侧有细细的“水洼”（几处）。

### frost_forest —— 霜林（S4）
- 2900×1080，far/mid/near。地面线 y=832（一条小径从左穿到右）。

### snow_hut —— 雪山小屋（S4）
- 2900×1080，far/mid/near。地面线 y=832（雪地）。

- 额外 `snow_hut_near_clear`（只画 near 层，同一尺寸/变体）：把门前的雪铲开了，露出一条深色的小路（从门 x≈1880 向右延伸到 x≈2900，y≈832，宽≈160）和门槛，雪堆在路两边。影片里 near 和它做淡入淡出。

### hut_in —— 小屋里面（S4：铃儿开口）

### grassland —— 草原（S5 开头：牧人和篝火）

### kitchen —— 奶奶家的灶间（S2 开头：包针）

## 3. 城、塔、天、火山（Agent C）

### gate —— 主城的城门（S5）
- 2900×1080，far/mid/near。地面线 y=832（城门前的土路/石板路）。
- 中式城墙：青砖大墙横贯整个画面（墙顶 y≈400，垛口，墙厚），墙上旗子在风里扬；**城门楼在 x≈1500**（两层，灰瓦，飞檐，木柱，红色柱子要降饱和成土红灰），**城门洞在 x≈1500，宽 260 高 330，两扇厚木门关着（铜钉）**；城墙前的路面；右侧 x 2000~2800 是城下街边：店铺（木板门脸、挑出的布幌子）、停着的板车、一个卖米的摊子；左侧 x 200~800 一棵树、拴马桩。远景是灰蒙蒙的城里屋顶和更远的山。窗里/灯笼里的光一律是纸白冷光。
- **不要欧式**：没有尖顶塔楼、没有圆拱城堡。

### hall_king —— 殿上（S5）
- 2400×1080，far + near。地面线 y=832。
- 中式大殿内景：高大的木柱（土红灰，降饱和）、梁枋、藻井的暗影；**后方正中 x≈1200 一个三级台阶的高台，台上一张宝座（高背椅，国王精灵坐在上面，宝座座面 y≈640）**，座后一面大屏风；两侧立柱 x≈330、x≈2070 框住；地面是方砖；两边 x≈600 和 x≈1800 地上留位置站官员。灯光是冷白，墙上挂旗子/帷幔（灰蓝、灰金）。
